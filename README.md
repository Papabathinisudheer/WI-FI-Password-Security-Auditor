# Wi-Fi Password Security Auditor

## Project Overview

Wi-Fi Password Security Auditor is a Python-based
cybersecurity project designed to analyze password
strength and provide security recommendations.

This project helps users understand password
complexity and improve wireless network password security.

## Features

- Password Strength Analysis
- Weak Password Detection
- Common Password Detection
- Password Complexity Checking
- Secure Password Generator
- Security Recommendations
- TXT Audit Report Generation
- Menu-Driven Interface
- Local Password Processing

## Technologies Used

- Python 3
- Visual Studio Code
- Python Standard Library

## Installation

Clone the repository:

git clone https://github.com/Papabathinisudheer/Wi-Fi-Password-Security-Auditor.git

Navigate to the project folder:

cd Wi-Fi-Password-Security-Auditor

## Execution

Run the program:

python3 wifi_auditor.py

## Usage

1. Run the program.
2. Select Password Audit.
3. Enter a sample Wi-Fi password.
4. View the password strength result.
5. Review security recommendations.
6. Save the audit report.

You can also select the Secure Password Generator
option to generate a random password.
